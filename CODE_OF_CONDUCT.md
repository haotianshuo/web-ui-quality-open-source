# Code of Conduct

We want this project to be a respectful, useful place to discuss Web quality,
verification, and safe AI-assisted changes.

Participants are expected to:

- be respectful and specific when disagreeing;
- focus criticism on ideas, code, and evidence, not people;
- protect private information and never post credentials, cookies, storage
  state, or personal data;
- keep reports and contributions relevant to the project.

Harassment, discrimination, threats, deliberate exposure of private data, and
knowingly misleading evidence are not acceptable.

If a concern cannot be handled in a public issue, contact `xrlcom@126.com`.
Do not include secrets or private customer data in the message.
