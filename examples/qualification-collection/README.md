# External Qualification Collection Templates

These are request templates, not proof artifacts. A HostGovernanceProvider or independent evaluator must complete verification outside WUQ's authority boundary.

- `host-attestation-response.example.json` shows the fields an external Host provider should return after verification.
- `independent-label-response.example.json` shows the fields an independent evaluator should provide.

Do not place secrets, raw prompts, source files, credentials, or pseudonymization keys in collection packs.
